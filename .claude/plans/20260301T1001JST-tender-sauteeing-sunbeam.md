# SPEC.ja.md 仕様書化 + 実装差分修正プラン

## Context

SPEC.ja.md は元々「実装指示書」として書かれたが、今後は正式な「仕様書」として使用する。
以下の 3 つの作業を行う:

1. 指示的な文言を仕様書として適切な宣言的文言に変換
2. 実装されているが SPEC に記載がない機能を追記
3. SPEC に記載があるが実装と異なる箇所を修正

**実行時ルール**: 実装開始前に全変更を ToDo リストに起こし、タスクごとに順次実行する。
